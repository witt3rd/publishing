What a build checks

Nothing is written until it passes the lint and the scan

A problem stops the build; the file is not written.

CheckFails when
LayoutContent leaves its page or frame, runs into the footer, or text is too faint to read.
FontsText is set in a face that is not vendored, so another machine would render it differently.
SecretsA token, key, e-mail address or home path appears in the text.
WordsThe repo's own private words appear, or a relative day word that goes stale.
RebuildThe committed file no longer matches a fresh build of its source (CI).

The video format

A folder with video.html becomes an MP4

The same source folder, the same theme, the same pinned render, one more output.

1 · WRITE

Scenes of HTML

Each scene is a deck slide on the timeline. Motion is CSS animation; nothing loads from the network.

2 · RENDER

Frame by frame

HyperFrames seeks every frame in the pinned Chromium and ffmpeg encodes them. No clock, no randomness.

3 · CHECK

The same frames

One toolchain gives the same bytes. Another ffmpeg must stay within a stated tolerance.
